# 英語の核心 — 中学英語からTOEIC・英会話へ

「なぜそうなるのか」から英語を学び直すための、完全無料・ビルド不要の静的Webアプリです。
中学英語 → 高校英語 → TOEIC → 英会話 の順に進みます。

- 有料API・アカウント登録・サーバーは不要（HTML / CSS / JS のみ）
- 学習記録はブラウザの localStorage に保存
- 音声はブラウザ標準の Web Speech API（読み上げ・音声認識）だけを使用

## 収録内容（全59単元）

| 段階 | 単元数 | 内容 |
|---|---|---|
| 中学英語 中1 | 13 | 語順、be動詞、一般動詞、否定・疑問、三単現、疑問詞、冠詞、代名詞、命令文、進行形、can、過去形、前置詞 |
| 中学英語 中2 | 10 | 過去進行形、未来、助動詞、不定詞、動名詞、There is、比較、接続詞、文型、受動態 |
| 中学英語 中3 | 7 | 現在完了、現在完了進行形、関係代名詞、分詞、間接疑問、不定詞の発展、仮定法の入口 |
| 高校英語 | 11 | 時制の全体像、助動詞の発展、仮定法、関係詞の発展、分詞構文、準動詞、冠詞、前置詞、比較の発展、強調・倒置、読解の基礎 |
| TOEIC 600 | 10 | 頻出語彙（職場・取引）、Part 1〜7 の解き方、時間配分と数字の聞き取り |
| 英会話 | 8 | 旅行（空港・ホテル・道案内）、仕事（自己紹介・会議と電話）、日常の雑談、音の変化、瞬間英作文の総合 |

各単元は「つまずき → 核心 → 例文 → 練習（8問）→ 話す（5文）」の5ステップです。解説・例文・問題はすべてオリジナルです。

## 起動方法

教材を JSON ファイルから読み込むため、**ファイルをダブルクリック（file://）では動きません**。
次のどちらかで開いてください。

### A. ローカルで動かす（PC）

このフォルダで簡易サーバーを起動し、ブラウザで `http://localhost:8765` を開きます。

```bash
python -m http.server 8765
```

Python がない場合は Node.js でも動きます。

```bash
npx serve -l 8765 .
```

VS Code の「Live Server」拡張でも開けます。

### B. GitHub Pages で公開する（スマホで使う場合におすすめ）

スマホでの発話チェック（マイク）は https のページでないと使えないことが多いため、スマホで使うならこの方法がおすすめです。無料で、git などの道具がなくても、ブラウザだけでできます。

**1. リポジトリを作る**

1. https://github.com で無料アカウントを作り、ログインする
2. 右上の「+」→「New repository」を選ぶ
3. Repository name に名前を入れる（例：`eigo-core`）。**Public** を選ぶ（無料の GitHub Pages は Public が必要）
4. 「Add a README file」などのチェックは付けずに「Create repository」を押す

**2. ファイルをアップロードする**

1. できたリポジトリの画面で「uploading an existing file」のリンク（または「Add file」→「Upload files」）を押す
2. このフォルダの中身をまとめてドラッグ＆ドロップする：`index.html`、`.nojekyll`、`README.md`、`CLAUDE.md`、`css`、`js`、`data`、`tools`
   - `.claude` フォルダは開発用なので入れなくてよい
   - 一度にアップロードできるのは100ファイルまで（このアプリは約70ファイル）
3. 画面下の「Commit changes」を押す

**3. 公開をオンにする**

1. リポジトリの「Settings」→ 左の「Pages」を開く
2. 「Build and deployment」の Source を「Deploy from a branch」、Branch を `main` と `/ (root)` にして「Save」
3. 数分待つと、同じ画面の上に公開URLが表示される（`https://<ユーザー名>.github.io/<リポジトリ名>/`）

**4. スマホで使う**

- 公開URLをスマホのブラウザで開き、「ホーム画面に追加」するとアプリのように開けます（iPhone は Safari の共有ボタンから、Android は Chrome のメニューから）
- 初めて 🎤 を押したときにマイクの使用許可を求められたら「許可」を選びます
- 学習記録はその端末のブラウザに保存されます。PCで試した記録は引き継がれません（必要なら「設定・データ」の書き出し／読み込みで移せます）

**更新するとき**

変更したファイルを、同じく「Add file」→「Upload files」で上書きアップロードします。JS や CSS を変えたときは、`index.html` の `?v=20261111` の日付を新しくしてから一緒にアップロードしてください（スマホに古いファイルが残らないようにするため）。

git に慣れている場合は、このフォルダで `git init` してリポジトリに push しても同じです（`.gitignore` で `.claude` は除外済み）。

## 使い方

1. **診断テスト**（12問・約3分）で、どの段階から始めるかの提案を受ける（スキップも可）
2. **ホーム**の「今日のメニュー」に沿って進める（復習カード → 単元1つ → 瞬間英作文。合計 約15分）
3. 各単元は「つまずき → 核心 → 例文 → 練習 → 話す」の5ステップ
4. 段階の最後に**確認テスト**（10問・80%で合格）。合格で次の段階が開く。「ロックを外して先に進む」で自由に進むこともできる

### タブ

| タブ | 内容 |
|---|---|
| ホーム | 今日のメニュー、進み具合 |
| コース | 段階→単元の一覧、確認テスト |
| 復習 | 単語カード（間隔反復）、間違えた問題の解き直し |
| 英作文 | 瞬間英作文（日本語→英語を話す／書く） |
| 記録 | 連続日数、直近14日の学習量、苦手項目、単元別正答率 |

### 音声について

- **読み上げ**：ほぼすべてのブラウザで使えます。速さと声は「設定」で変更できます
- **TOEIC のリスニング（Part 1〜4）**：▶ で音声が流れます。Part 1・2 は選択肢も音声だけ（(A)(B)(C) のボタン）です。Part 3・4 は自動では流れないので、設問を読んでから ▶ を押してください。答えたあと「スクリプト」で英文を確認できます。会話は2人の声の高さを変えて読み上げます
- **音声認識（発話チェック）**：Chrome / Edge / Safari など対応ブラウザのみ。非対応の場合は🎤ボタンが出ず、入力で練習します
- 音声認識はブラウザがネット上の認識サービスを使うことがあります（無料・登録不要）

### データの移動・リセット

ホーム下部の「設定・データ」から、学習記録を JSON で書き出し／読み込みできます。別の端末に移すときに使ってください。「すべての記録を消す」で初期化できます。

## ファイル構成

```
index.html          画面の骨組み
css/style.css       スタイル（スマホ優先、ダークモード対応）
js/app.js           画面とルーティング
js/quiz.js          問題の描画・判定、本文のマークアップ
js/storage.js       localStorage への保存・学習記録
js/srs.js           間隔反復（簡易SM-2）
js/speech.js        読み上げ・音声認識
data/index.json     コース構成（段階と単元の一覧）
data/diagnostic.json 診断テスト
data/units/*.json   単元ごとの教材
tools/check_units.py 教材JSONのチェック（python -I tools/check_units.py .）
```

教材の追加方法や設計方針は [CLAUDE.md](CLAUDE.md) を参照してください。
